# Code Review

## Kiểm tra

- correctness
- architecture
- readability
- maintainability
- error handling
- security
- performance
- testing
- dependency usage
- documentation

## Output

Phân loại:

### Critical

Phải sửa.

### Important

Nên sửa.

### Suggestion

Có thể cải thiện.

### Good

Điểm triển khai tốt.

Không tự sửa code khi task chỉ yêu cầu review.
